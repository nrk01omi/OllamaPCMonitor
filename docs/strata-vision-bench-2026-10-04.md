# Strata / Qwen3.8-Flash-Next vision 検証（2026-10-04）

## 起動

通常の画像対応版は `powershell -File scripts\Start-Strata-Vision-128K.ps1`。最大コンテキストの検証版は `powershell -File scripts\Start-Strata-Vision-512K.ps1`。いずれも `0.0.0.0:8082` で待ち受け、`Ctrl+C` で終了する。両者は同じポートと GPU を使うため同時には起動できない。元のテキスト専用設定 `C:\Apps\Strata\strata-iq2_xs.json` は維持した。

画像版の設定ファイルは `C:\Apps\Strata\strata-iq2_xs-vision-{128k,262k,384k,512k}.json`、画像エンコーダーは `D:\Strata-data\models\mmproj-Qwen3.8-Flash-Next-BF16.gguf`。前者の起動スクリプトが設定とエンコーダーの存在を確認する。セットアップには Strata の `--vision gpu` を使用した。

## 画像入力

`/v1/status` で `vision.enabled=true`、`vision.available=true` を確認。PNG に書いた `VISION 42` を OpenAI 互換の `/v1/chat/completions` に `image_url` の data URL として送ると、128K 版と 512K 版の両方で `VISION 42` と返した。従来の `images:false` / HTTP 400 はテキスト専用設定で起動していたためであり、この構成では画像を入力できる。動画入力は未検証。

## 推論性能比較

同一の合成テキスト入力と180出力トークンをそれぞれ3回実行。以下は中央値。GPU は RTX 5090 32GB、モデルは IQ2_XS、コンテキストは双方131,072、KV は int8。

| 入力長 | 構成 | 入力処理 | 出力生成 | 全応答時間 |
| --- | --- | ---: | ---: | ---: |
| 約6,056トークン | テキスト専用 | 5,304 tok/s | 183 tok/s | 2.16秒 |
| 約6,056トークン | 画像対応 | 5,092 tok/s | 188 tok/s | 2.17秒 |
| 約24,099トークン | テキスト専用 | 5,718 tok/s | 195 tok/s | 5.18秒 |
| 約24,099トークン | 画像対応 | 5,593 tok/s | 190 tok/s | 5.32秒 |

画像対応によるテキスト入力処理速度の差は約2〜4%、出力生成は測定の揺れの範囲。画像を実際に入力した場合の速度は画像サイズや枚数に依存するため、この表には含めない。生データは [テキスト専用](strata-text-128k-bench.json) と [画像対応](strata-vision-128k-bench.json)。

## コンテキスト上限

長い合成入力の中間に `ORCHID-4827` を一度だけ埋め、入力末尾でその文字列を質問した。各構成を一回ずつ試し、応答・空き RAM・処理時間を記録した。

| 設定上限 | KV / 拡張 | 実入力 | 正答 | 所要時間 | 終了後空き RAM |
| ---: | --- | ---: | --- | ---: | ---: |
| 262,144 | int8 / なし | 249,679 | ○ | 48.34秒 | 4.83 GiB |
| 393,216 | q4_0 / YaRN 1.5倍 | 367,142 | ○ | 77.24秒 | 6.13 GiB |
| **524,288** | **q4_0 / YaRN 2倍** | **513,969** | **○** | **115.0秒** | **5.47 GiB** |

この環境で起動と上限付近の正答を確認した最大設定は **524,288トークン（512K）**。512K では画像入力も成功した。262K は拡張なしで確認した最大設定。512K の読み出しは約4,506入力 tok/s、約91.6出力 tok/s（出力9トークンのみなので後者は参考値）。詳細は [262K](strata-vision-262k-needle.json)、[384K](strata-vision-384k-needle.json)、[512K](strata-vision-512k-needle.json)。

512K は YaRN と q4_0 KV を使った実験設定で、長文の品質全般、複数画像、同時リクエストまでは保証しない。通常使用は128K設定、長文が必要なときのみ512K設定を選ぶ。各設定での同時起動は不可。
